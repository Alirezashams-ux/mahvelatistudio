# Mahvelati Studio Design System

## Design idea

Scientific editorial design combined with physical-system instrumentation.

The website should not look like a generic AI startup.

## Semantic colors

Model / prediction:
#244BFF

Physical reality / disturbance / contradiction:
#FF4F19

Paper:
#F3F0E8

Ink:
#111214

Graphite:
#57595F

## Principle

Color communicates meaning.

Blue is not decoration.
It represents the model.

Orange is not decoration.
It represents reality, disturbance, threshold crossing, or contradiction.

## Visual language

- scientific paper
- engineering notebook
- instrumentation
- physical systems
- editorial typography
- restrained interaction
